# Fluxo de implementação

Ao concluir cada implementação:

1. Execute as verificações apropriadas às alterações.
2. Atualize a documentação e o estado da fase correspondente.
3. Revise o diff e versione todas as alterações pertinentes com um commit Git
   descritivo. Preserve alterações preexistentes sem relação com a implementação.
4. Informe o hash do commit e o resultado das verificações na entrega.

Não versione credenciais, `.env`, ambientes virtuais, caches ou dados locais.
Não faça push para um remoto sem solicitação do usuário.
